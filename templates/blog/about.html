О проекте

Учебное веб-приложение на фреймворке Django, разработанное в рамках практической работы по веб-программированию.

Возможности

  • Список опубликованных статей с пагинацией на главной странице;
  • Просмотр отдельной статьи по её слагу;
  • Рубрикация статей по категориям;
  • Административная панель Django для управления контентом.

Технологии

  • Python 3.10+
  • Django 4.2
  • SQLite (база данных по умолчанию)
  • HTML/CSS-шаблоны Django Template Language
