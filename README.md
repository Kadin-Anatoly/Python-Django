# 🐍 Python Django Приложение — Практическая работа

> _"Практика — основа мастерства в программировании."_ 💬

Этот репозиторий содержит учебное **Django-приложение** — блог со статьями и категориями, разработанный в рамках практической работы по веб-программированию. Проект демонстрирует базовые принципы создания веб-приложений с использованием фреймворка **Django**.

Цель проекта:

- Научиться создавать Django-проекты и приложения.
- Освоить работу с виртуальным окружением.
- Научиться применять миграции и запускать сервер.
- Познакомиться с моделями, представлениями, шаблонами и админ-панелью Django.
- Оформить проект с помощью `README.md`.

## 📦 Необходимые зависимости

Для корректной работы приложения необходимо установить следующие пакеты. Рекомендуется использовать **виртуальное окружение** для изоляции зависимостей.

| Пакет        | Версия       | Назначение                          |
|-------------|--------------|-------------------------------------|
| Python      | 3.10 или выше | Язык программирования               |
| Django      | 4.2.x         | Веб-фреймворк                       |
| Pillow      | 13.x          | Работа с изображениями (ImageField) |
| pip         | Последняя     | Менеджер пакетов Python             |
| virtualenv  | Последняя     | Создание виртуальных окружений     |

> ⚠️ Убедитесь, что Python установлен в системе. Проверьте командой:
> ```bash
> python --version
> ```

Точные версии пакетов зафиксированы в файле `requirements.txt`.

## ⚙️ Установка и запуск

### 🔧 Создание виртуального окружения

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Kadin-Anatoly/Python-Django.git
cd Python-Django

# 2. Создайте виртуальное окружение
python -m venv venv

# 3. Активируйте его:

# — Для Windows:
venv\Scripts\activate

# — Для Linux/macOS:
source venv/bin/activate

# 4. Установите зависимости
pip install -r requirements.txt
```

### 🔁 Запуск миграций

Перед запуском приложения необходимо применить миграции — они создадут необходимые таблицы в базе данных (SQLite).

```bash
python manage.py migrate
```

### 📊 Загрузка демонстрационных данных (опционально)

```bash
python manage.py loaddata blog/fixtures/demo_data.json
```

### 🚀 Запуск сервера разработки

```bash
python manage.py runserver
```

После запуска приложение будет доступно по адресу: **http://127.0.0.1:8000/**

Админ-панель: **http://127.0.0.1:8000/admin/** (создайте суперпользователя командой `python manage.py createsuperuser`).

### 🧪 Запуск тестов

```bash
python manage.py test
```
